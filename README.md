# 🚀 Đông Đô CS Core V2 — Enterprise Architecture

Hệ thống Chăm Sóc Khách Hàng Thông Minh & Quản Trị Tri Thức Đông Đô Partners phiên bản 2.0.

Được tái cấu trúc hoàn toàn từ Python/JS sang **Golang (Gin + SQLC + Goose) + Next.js (TypeScript)** theo chuẩn **Clean Architecture**, tích hợp **Redis Streams Event Bus**, **Qdrant Vector DB** và **WebRTC Voice Calling**.

---

## 🛠️ Công Nghệ Sử Dụng

| Thành phần | Công nghệ | Chi tiết |
|---|---|---|
| **Backend API** | Go 1.26 / Gin / pgx v5 / **SQLC** | Clean Architecture, type-safe SQL, Zero Allocations |
| **Migrations** | **Goose v3** | Embedded trong binary, Up/Down trong 1 file SQL |
| **Frontend** | Next.js 14 / TypeScript / TailwindCSS | Dark Glassmorphism, Micro-animations |
| **Realtime** | WebSocket Hub + Goroutines | Auto-reconnect, Typing Indicator, Heartbeat Ping/Pong |
| **Event Bus** | Redis Streams | Consumer Groups (`ws_group`, `ai_group`, `db_group`), XACK, XAUTOCLAIM, DLQ |
| **Redis State** | Redis Key-Value & Sets | Distributed Lock, Unread Counter, Typing State (TTL 3s) |
| **Vector DB** | Qdrant (gRPC) | Vector search cosine, metadata filtering, continuous learning |
| **LLM Engine** | Claude Haiku 4.5 / Sonnet / Opus | RAG Pipeline tiếng Việt, Zero hallucination |
| **Voice Calling** | WebRTC (P2P Audio) | Gọi điện thoại 2 chiều qua trình duyệt, STUN server, ghi âm |
| **Database** | PostgreSQL 16 | Source of Truth, Batch Upsert (pgx.Batch), Idempotent |

## 🔧 Cài Đặt Công Cụ (Dev Setup)

Cần 2 binary: **sqlc** (generate code) và **goose** (migrations).

```bash
# Tải sqlc v1.27.0 (Darwin ARM64)
curl -sSL https://github.com/sqlc-dev/sqlc/releases/download/v1.27.0/sqlc_1.27.0_darwin_arm64.zip -o /tmp/sqlc.zip
unzip -o /tmp/sqlc.zip sqlc -d tools/bin/
chmod +x tools/bin/sqlc

# Tải goose v3.22.1 (Darwin ARM64)
curl -sSL https://github.com/pressly/goose/releases/download/v3.22.1/goose_darwin_arm64 -o tools/bin/goose
chmod +x tools/bin/goose

# Verify
./tools/bin/sqlc version   # → v1.27.0
./tools/bin/goose --help  # → goose migration tool
```

## 🔄 Workflow Dev: Thêm / Sửa Database Query

### Bước 1: Viết SQL trong `db/queries/`

```sql
-- db/queries/auth/users.sql
-- name: GetUserByUsername :one
SELECT id, username, password_hash, salt, full_name, role, is_active, created_at
FROM users
WHERE LOWER(username) = LOWER($1);
```

### Bước 2: Chạy sqlc generate

```bash
make sqlc-gen
# hoặc: ./tools/bin/sqlc generate
```

**Output:** `internal/repository/sqlcdb/auth/users.sql.go` — tự động được tạo với:
- Struct `GetUserByUsernameParams` (type-safe params)
- Method `GetUserByUsername(ctx, params) (User, error)`

### Bước 3: Viết / cập nhật Repository adapter

```go
// internal/repository/postgres/user_repo.go
func (r *UserRepo) GetByUsername(ctx context.Context, username string) (*domain.User, error) {
    row, err := r.db.Auth.GetUserByUsername(ctx, authdb.GetUserByUsernameParams{
        Username: username,
    })
    if err != nil {
        if errors.Is(err, pgx.ErrNoRows) {
            return nil, nil
        }
        return nil, err
    }
    return &domain.User{
        ID: row.ID, Username: row.Username, Role: row.Role, ...
    }, nil
}
```

### Bước 4: Verify build

```bash
go build ./...
```

## 🗄️ Workflow Migrations (Goose)

### Cấu trúc migration file

```sql
-- db/migrations/00004_new_feature.sql
-- +goose Up
-- +goose StatementBegin
CREATE TABLE new_table (...);
CREATE INDEX ON new_table(...);
-- +goose StatementEnd

-- +goose Down
-- +goose StatementBegin
DROP TABLE new_table;
-- +goose StatementEnd
```

### Tạo migration mới

```bash
# Cách 1: Dùng goose CLI
./tools/bin/goose create add_new_feature sql

# Cách 2: Tạo tay
touch db/migrations/00004_add_new_feature.sql
# Viết nội dung với -- +goose Up / Down

# Copy vào embedded folder để binary nhận
cp db/migrations/00004_add_new_feature.sql internal/repository/postgres/migrations/
```

### Chạy migrations

```bash
# Tự động (server startup) — goose chạy trong NewDB()
make up

# Thủ công bằng goose CLI
make migrate-up
make migrate-down
make migrate-status

# Dùng Make shortcut
make migrate-create name=add_tags_column
```

### Reset hoàn toàn (⚠️ XÓA HẾT DATA)

```bash
make down
docker volume rm dongdo_cs_v2_pgdata
make up          # goose tự chạy migrations
```

## 🚀 Hướng Dẫn Khởi Chạy

### Cách 1: Docker Compose (Khuyên dùng)

```bash
# 1. Cấu hình API Key
cp .env.example .env
# Chỉnh sửa .env: điền ANTHROPIC_API_KEY

# 2. Build & Up toàn bộ hạ tầng
make up
# Docker Compose khởi: Postgres (port 5433) + Redis + Qdrant + Server

# 3. Nạp tài liệu vào Qdrant (sau khi server đã chạy)
docker compose exec server /app/ingest
```

### Cách 2: Chạy trực tiếp trên máy (Local Dev)

**Yêu cầu:** Postgres 16 (port 5433), Redis, Qdrant đang chạy.

```bash
# 1. Chạy migrations (goose tự chạy khi server start,
#    hoặc chạy thủ công)
./tools/bin/goose -dir internal/repository/postgres/migrations \
    postgres "postgres://postgres:postgrespassword@localhost:5433/dongdo_cs?sslmode=disable" up

# 2. Build & chạy server
go build -o server_new ./cmd/server
./server_new

# 3. Build & chạy ingest (nạp tài liệu Qdrant)
go build -o ingest_new ./cmd/ingest
./ingest_new

# 4. Frontend (terminal khác)
cd web && npm install && npm run dev
```

### Full Dev Workflow

```bash
# Generate sqlc → Build → Run
make dev

# Hoặc từng bước:
make sqlc-gen    # 1. Generate code
make build       # 2. Build binary
make migrate-up  # 3. Run migrations
./server_new     # 4. Chạy server
```

## 📌 Lưu Ý Quan Trọng

1. **KHÔNG edit** `internal/repository/sqlcdb/` — đây là code được **sqlc generate tự động**. Mọi thay đổi SQL → chỉnh sửa file trong `db/queries/` rồi chạy `make sqlc-gen`.

2. **KHÔNG edit** `internal/repository/postgres/migrations/` — đây là bản **embedded** của `db/migrations/`. Copy file mới vào đây sau khi tạo migration.

3. **Goose migrations** tự động chạy khi `NewDB()` được gọi (trong `cmd/server/main.go`). Không cần chạy thủ công trừ khi muốn migrate trước khi start server.

4. **Volume cũ (golang-migrate):** Nếu đã có volume chạy từ trước với golang-migrate, cần wipe volume để bắt đầu với goose:
   ```bash
   docker volume rm dongdo_cs_v2_pgdata
   ```
